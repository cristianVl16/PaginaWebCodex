# Portafolio de Cristian Washington Vasconez Loor

Sitio estático en español, preparado para publicarse en Netlify.

## Publicar en Netlify

1. Inicia sesión en Netlify y abre https://app.netlify.com/drop.
2. Arrastra la carpeta completa del proyecto (la que contiene `index.html`, `styles.css`, `script.js` y `assets/`).
3. Netlify publicará el sitio y te dará una dirección `netlify.app`. Este sitio estático no necesita comando de compilación.
4. Para recibir opiniones, abre **Forms** en el panel de Netlify, activa **Form detection** y vuelve a desplegar el sitio. Los comentarios llegarán al panel y deberán revisarse antes de publicarse como testimonios.

También puedes subir esta carpeta a un repositorio de GitHub y conectarlo con Netlify para que cada actualización se publique automáticamente.

El PDF y la foto se encuentran en `assets/`. El botón de LinkedIn lleva temporalmente a una búsqueda por nombre hasta que se añada el enlace de perfil personal.

El portafolio incluye el proyecto académico LUUV, una app de citas: https://luuv-spring.onrender.com/login

Las tarjetas iniciales del Libro de visitas son ejemplos ficticios y están marcadas como tales. Los mensajes reales se reciben de forma privada en Netlify; el formulario no los publica automáticamente.
